# Rock04 prototype relief normal

Unaccepted experiment BD. Original source: [Poly Haven Rock04](https://polyhaven.com/a/rock_04), Rob Tuytel, CC0. Original maps are preserved in ../rock_04.

Derived RGB8 OpenGL normal: periodic central differences of full16-bit grayscale height at box mip3, tile1.5 m, authored interval0.16 m; add original normal-slope residual after mip3 removal, capped to unit length. Approximate height filtering, not exact engine mip reconstruction. Runtime flips GL green. Manifest records source/output hashes; fine residual cap affects0.4879% of texels.

PNG source alpha65533..65535 is ignored; unassociated grayscale is height. This asset is neither accepted art nor proof of visual/performance quality.
