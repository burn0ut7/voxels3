# Brown Mud03 dirt prototype

Source: [Brown Mud03](https://polyhaven.com/a/brown_mud_03), Rob Tuytel,
[CC0](https://polyhaven.com/license). Imported2026-09-19.

Unaccepted candidate BX. Documented tile width1.3m. Authored displacement
interval100mm; this is a prototype art choice, not measured scan depth.
The height PNG preserves the linear EXR values without range remapping.
Color, AO, roughness and source GL normals are original2K PNGs.
The runtime normal combines mip2 height slopes at this physical scale with
a capped fine residual of the source normal. See manifest.json for hashes
and the exact conversion. Source GL normal is retained as a bake input.

These scanned clods replace independently reshaped compacted dirt. The scan
contains wet/compacted patches and footprints; it is an art candidate, not
a universally suitable soil or a validation of the game's parallax shader.
